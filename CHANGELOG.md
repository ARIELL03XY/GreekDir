# Changelog

All notable changes to GreekDir. Versions with a `-beta.N` suffix are pre-releases. This file is published on the website as "What's new" (`docs/changelog.html`, generated by `npm run changelog`).

## [Unreleased]

## [1.0.0-beta.2] - 2026-11-08

The first beta for macOS.

### Added

- **macOS (beta).** Two DMGs: `arm64` for Apple Silicon (M1 or later) and `x64` for Intel Macs, macOS 13 or later. They are not signed with an Apple Developer ID yet, so the first time macOS says it cannot verify the developer: open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Full Disk Access hint (macOS).** When a scan finds folders that macOS keeps private (Documents, Desktop, Mail…), GreekDir says so and opens the right settings page; the detail panel of a locked folder has the same button.
- macOS now explains why GreekDir asks before reading protected folders or removable and network drives, and before asking Finder to empty the Trash (without that explanation macOS silently refused **Empty Trash**).

### Changed

- Every release now includes the Windows installer and both macOS DMGs, with one `SHA256SUMS.txt` for all of them. The macOS builds are checked automatically on a real Mac before each release: signature, architecture, and a launch that lists the disks and scans a folder.

## [1.0.0-beta.1] - 2026-11-08

The first public build.

### Added

- **Clean Up menu** (also in the right-click menu, with the same shortcuts): **Open** (Enter; programs and scripts ask before running), **Show in Explorer** (Ctrl+E), **Open Terminal Here** (Ctrl+T), **Move to Recycle Bin** (Delete, with a confirmation), **Move To…** (Ctrl+M; never overwrites, and a move to another drive copies then deletes the original) and **Empty Recycle Bin**, labelled with the number of items and their size. On Windows it also opens Disk Cleanup and Installed Apps. GreekDir still never deletes anything permanently except when you empty the Recycle Bin, and it runs nothing that needs administrator rights.
- **Menu bar.** File (Select Folder…, Ctrl+O; Exit), Edit, View (zoom, full screen) and Help → **About GreekDir**, which shows the app version, the Electron/Chromium/Node.js versions and the copyright, with a button to copy that information for support requests. The menu follows the app's language (English/Spanish). macOS uses its native About panel. There is still no Reload in production builds.
- **Refined app icon.** The plate has straight sides with continuous-curvature corners, a defined rim, a top highlight and a soft shadow, so its edges stay visible on light and dark backgrounds; the blocks have subtle outlines. Windows gets a real multi-size `.ico` with hand-tuned 16 and 32 px versions. Icons are rendered from the SVG sources with `npm run icons`.
- **Single instance.** Launching GreekDir while it is already open brings the existing window to the front (restoring it if minimised) instead of opening a second copy that would share the same settings files. The installer's "Run once" mode uses its own temporary data folder and is not affected.
- **CI and releases.** GitHub Actions runs lint, typecheck, tests and a production dependency audit on every push and pull request, and builds the Windows installer. Pushing a `v*` tag builds the installer and creates a **draft** GitHub release with its SHA-256. Dependabot keeps npm packages and the (SHA-pinned) actions up to date.
- **Run once, without installing**: the Windows installer now opens with a choice between installing GreekDir and running it once. "Run once" unpacks the app into a temporary folder, runs it with temporary settings, and deletes everything when it is closed — no registry entries, shortcuts or saved preferences. Also available as `GreekDir-Setup.exe /RUNONCE`. See `build/README.md`.
- **Duplicate finder**: a "Duplicates" tab groups files by size, hashes the size-groups with the most potential wasted space first (bounded by a hash budget so it stays fast on large drives), and lists them sorted by wasted space, largest first.
- **Cleanup suggestions**: a "Cleanup" tab surfaces known build-artifact/cache/dependency folders already present in the scan (`node_modules`, `dist`, `.cache`, …), sorted by size.
- **Multi-select + bulk trash**: checkboxes in the List, Top files, Duplicates, and Cleanup tables, with a floating action bar to move several items to the trash at once (two-step confirm, same as the single-file action).
- **Keyboard shortcuts**: `Ctrl/Cmd+F` focuses the search box; `Escape` closes the detail panel.
- **Configurable exclude filters**: add extra folder names to skip during a scan (beyond the built-in system/hidden skip list), persisted across sessions.
- **Global search**: the toolbar search box now searches the entire scan (files and folders), largest first, with details and context-menu actions on every result.
- **Category breakdown**: the treemap view shows a stacked bar of the current folder's bytes by file type, with sizes and percentages.
- **Dark mode**: light/dark toggle in the header, persisted across sessions and following the OS theme on first run.
- **Export report**: save the scan as CSV (top 100 files) or JSON (summary + folders + top files) via a native save dialog.
- **Context menu**: right-click any row or treemap tile for Details / Show in folder / Move to trash.
- **Column sorting**: click Name or Size in the list view to reorder.
- **Filter box**: filter the list and top-files views by name or extension.
- **Modified date**: files now carry their last-modified date, shown in the detail panel.
- **Top files view**: ranked list of the 100 largest files across the whole scan, with full path, share of total, and quick actions.
- **File actions**: "Show in folder" (Finder/Explorer) and "Move to trash" (with two-step confirmation) from the detail panel.
- **Rescan button** in the results toolbar to refresh the current folder.
- **Hidden folders toggle**: optionally include hidden/system folders (`.git`, `node_modules`, …) in the scan.
- **Language persistence**: the en/es choice is remembered across sessions and defaults to the OS language on first run.
- **Window state persistence**: size and position are restored on relaunch.
- Custom application menu; production builds drop View/Reload so an accidental Ctrl+R/Cmd+R can no longer lose scan results.
- Permission-denied folders are now flagged (lock icon + notice) instead of silently reading 0 B.
- Windows installer build script: `build:win`.
- Privacy policy and support pages on the website.

### Security

- **Electron 31 → 45** (Chromium 126 → 156). The previous version was out of support and carried dozens of published advisories.
- **No more network access.** Inter and JetBrains Mono are now bundled with the app (SIL OFL-1.1) instead of being loaded from Google Fonts, so GreekDir really never connects to the internet. A full page reload makes only local file requests.
- **Content-Security-Policy** in the packaged app (own files only; no network, plugins or inline scripts), plus an explicit renderer sandbox, no new windows, no navigation away from the app, and all browser permission requests denied.
- **Electron fuses hardened**: `ELECTRON_RUN_AS_NODE`, `NODE_OPTIONS` and `--inspect` are disabled, and the app can only load from an integrity-checked `app.asar`. The packaged binary can no longer be used as a general-purpose Node interpreter.
- **IPC hardening.** Every main-process handler now rejects calls that do not come from the app's own main window, validates its arguments, and only acts on paths that exist in the current scan. The scan root and filesystem roots can never be trashed, and anything outside the scan (relative paths, `..` traversal, NUL bytes, wrong types) is refused.

### Changed

- **Minimum macOS is now 13 (Ventura)**, a consequence of the Electron 45 upgrade (Windows 10 or later is unchanged). The website, its privacy policy and its support page were updated accordingly and now describe the Install / Run once installer, the no-network guarantee and the new safeguards.
- **Direct distribution only.** The Microsoft Store (APPX) build, its configuration and its scripts were removed. React, D3 and the fonts are bundled by Vite, so the app now ships no runtime dependencies: `app.asar` went from 8.7 MB to 0.6 MB and the installer shrank accordingly.
- Build toolchain upgraded: Vite 5 → 8, `@vitejs/plugin-react` 4 → 6, `vite-plugin-electron` 0.28 → 1.2 and Vitest 3 → 5. This clears every critical and high advisory in the development dependency tree (29 → 11, all moderate). `vite-plugin-electron-renderer` was removed: the sandboxed renderer uses no Node modules. Tailwind 4 and ESLint 10 were deliberately not adopted (large, not security-driven).
- The `LICENSE` and the website footer now credit `CHV Network Technologies`.
- The scanner, duplicate finder, cleanup finder and search moved out of `electron/main.ts` into Electron-free modules (`electron/scanner.ts`, `electron/validation.ts`), and `npm test` (Vitest) now covers them. `npm run lint` also covers `electron/`.
- The publisher and author metadata now read `CHV Network Technologies` (executable, installer, uninstaller entry) and `ARIELL03XY` (package author), and the application ID is `com.chvnetworktechnologies.greekdir`.

### Fixed

- Exclude patterns changed on the welcome screen were ignored until another setting changed (stale callback).
- **Bulk move to trash no longer ignores failures.** The result bar now says how many items were really moved and how many were not (in use, no permission, already gone); the ones that failed stay selected so they can be retried, and the right-click menu now shows an error instead of silently closing. Trashed items disappear from every view and from the scan cache.
- **Duplicates: the last copy is protected.** Selecting every copy of a duplicate group disables "Move to trash" and explains why, so a file can no longer be deleted by accident.
- **The window can no longer open off-screen** when it was last used on a monitor that is no longer connected: the saved position is ignored (the size is kept) and the window is centred.
- **macOS**: scanning `/` no longer double-counts data through APFS firmlinks (`/System/Volumes/Data`) and no longer descends into `/Volumes` (external drives are scanned individually).
- **macOS**: the disk list hides APFS helper volumes (Preboot, Update, Data, VM) and reports real container usage instead of the sealed system volume's own blocks.
- **macOS**: frameless window is draggable again (missing drag-region CSS) and the traffic lights no longer overlap the header.
- **Windows**: the native window frame is kept (the macOS-only `hiddenInset` title bar is no longer applied) and `System Volume Information` is skipped during scans.
- Treemap drill-down works again for directories above the IPC depth cutoff.
- Faster deep navigation: `expand-directory` resolves paths by prefix descent instead of walking the whole tree.
- Scan errors return the UI to the start screen instead of leaving it stuck on "Scanning…".
- Long breadcrumb trails scroll (and auto-scroll to the current folder) instead of overlapping the toolbar.
